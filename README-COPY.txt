Dash Dental — UI update pack (workspace shell + dashboard cockpit)
================================================================

Скопируй содержимое этой папки в КОРЕНЬ своего репозитория с заменой файлов
(структура папок уже совпадает с проектом).

Файлы в этом архиве-паке:
  tsconfig.json
  src/app/globals.css
  src/app/(workspace)/dashboard/page.tsx
  src/features/app-shell/layouts/workspace-layout-shell.tsx
  src/features/dashboard/components/recovery-cockpit.tsx
  src/features/i18n/translations.ts

После копирования в репозитории выполни:
  npm run typecheck
  npm run lint
  npm run build

Путь к этой папке на диске:
  C:\Temp\DentalRecovery-UI-update
